# ШиШаНи Центр — автообновление

Первый релиз: **1.0**.

## Установка
1. Скопируй `Shishani_Center.lua` и `Shishani_Updater.lua` из установочного ZIP в папку `GTA San Andreas/moonloader/`.
2. Удали старые копии скрипта, чтобы не было двойных команд `/mem`.
3. Запусти SA-MP. Меню открывается командой `/mem`.

## Автообновление
- Проверка GitHub автоматически при запуске и затем каждые 30 минут.
- Команда `/shupdate` проверяет новую версию вручную.
- Новая версия загружается и проверяется на базовую корректность, а предыдущий файл сохраняется как `Shishani_Center.lua.bak`.
- После установки обновления **перезапусти игру**, чтобы загрузился новый код.
- Скрипт работает локально, без GitHub-токена и без отправки данных игроков.

## Как выпустить обновление
1. Измени `shishani-center/Shishani_Center.lua` в кодировке **UTF-8**. В нём установи `script_version("1.1")` (или следующий номер).
2. Обнови `shishani-center/version.txt` до того же номера (`1.1`).
3. Сохрани изменения в ветке `master`. Во время следующей проверки автообновлятор скачает новый файл.

**Важно:** файл из GitHub хранится в UTF-8, а установленный MoonLoader-файл автоматически перекодируется в CP1251. Не копируй UTF-8 исходник прямо в игру вместо файла из установочного архива.
